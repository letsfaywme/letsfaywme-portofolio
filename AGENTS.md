The recreated profile section should feel:

- Premium
- Futuristic
- Smooth
- Interactive
- Responsive
- Modern and elegant

---

# Main Objective

Transform the current static profile/project card into an immersive interactive experience using:

- 3D card interaction
- Physics-based lanyard effect
- Smooth animations
- Glassmorphism UI
- Glow effects
- Responsive layout
- Modern typography

The result should look visually impressive but still clean and professional.

---

# Design Requirements

## Card Design

The profile/project card should:

- Use rounded modern corners
- Have glassmorphism styling
- Include subtle gradients
- Feature glow/highlight effects
- Support hover interaction
- Include smooth depth movement
- Feel lightweight and premium

Avoid:

- Overly bright neon effects
- Excessive blur
- Oversized cards
- Cluttered layouts

---

# 3D Interaction

Integrate an interactive 3D card system inspired by realistic hanging ID/lanyard cards.

Requirements:

- Smooth physics movement
- Mouse/touch interaction
- Drag interaction
- Realistic swinging animation
- Responsive behavior on mobile
- Optimized performance

Use:

- React Three Fiber
- Drei
- Rapier Physics
- Meshline

The interaction must feel natural and fluid.

# Responsive Rules

The profile section must:

- Scale perfectly on mobile
- Maintain aspect ratio
- Avoid overflow issues
- Reduce heavy effects on low-end devices
- Keep smooth interaction across screen sizes

Mobile optimization is mandatory.

---

# Animation Guidelines

Use smooth and elegant motion:

- Framer Motion preferred
- Smooth easing
- Soft transitions
- Hover lift effect
- Fade and scale animations
- Subtle floating motion

Avoid:

- Abrupt movement
- Laggy physics
- Overly exaggerated motion

---

# Performance Optimization

Prioritize:

- GPU-friendly animations
- Lazy loading
- Optimized rendering
- Efficient physics calculations
- Mobile performance

The experience should remain smooth even on lower-end devices.

---

# Technical Requirements

- Next.js

- Modular
- Reusable
- Maintainable
